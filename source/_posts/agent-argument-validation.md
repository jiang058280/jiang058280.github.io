类型检查只能证明输入结构符合约定，不能说明操作合法。日期字符串可能格式正确但开始时间晚于结束时间，订单 ID 可能存在但不属于当前用户。

## 分层校验

先解析结构，再检查范围、字段关系与权限，最后执行工具。每一层返回可识别原因，便于模型修正可修正的问题；权限拒绝则不应通过反复改写参数绕过。

## 一个时间范围例子

用户要求查看最近三年的逐分钟数据，日期本身合法，但可能超过查询容量。服务可以要求缩小时间范围或改用汇总粒度，而不是直接执行一个高成本请求。

## 验收样本

包括缺字段、错误枚举、边界值、互斥字段和越权 ID。校验逻辑应在服务端复用，避免模型调用与普通 API 调用各有一套不一致规则。
